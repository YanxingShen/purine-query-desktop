## 一、验证方法与来源清单

### 1.1 方法
1. 程序化校验：用脚本逐条复核 `level` 与 `purine_mg_per_100g` 是否符合库内口径（低<75 / 中75–150 / 高150–300 / 极高>300，边界就高）。
2. 全量通读 `knowledge.json` 23 篇，对照权威指南逐条核对医学结论。
3. 抽取 **63 条**食物（≥50 要求），覆盖全部 14 个大类，重点覆盖高/极高嘌呤、争议食物、"未知"条目；对每条独立检索权威来源并与库值比对。
4. **关键动作**：直接抓取国家卫健委《成人高尿酸血症与痛风食养指南（2024 年版）》PDF 原文，逐行核对其**附录 1 表 1-2《常见食物嘌呤含量表》**（数据引自《中国食物成分表》第 6 版/第二册，杨月欣主编）。这是本库声称的主数据源，因此以该表原文为第一基准。

- 判定规则：null→未知；<75→低；75–<150→中；150–300→高；>300→极高；边界（75/150/300）就高。

## 四、发现的问题清单（按严重程度）

### 🔴 错误（必须修正）

**E1. 鹅肉(C052) 数值错误，误把"鹅肝"值当成"鹅肉"**
- 库值：377 mg/100g，level=极高（严格禁止）。
- 事实：2024 指南表 1-2 中**没有"鹅肉"这一行**。377 这一行对应的是 **鹅肝(C046，库中已正确录为377)**。表 1-1 明确把"鹅"列入 **75–150 第二类**；表 1-2 中鹅相关条目为：鹅肝377、鹅心259、鹅胗182/169、鹅脑140、烧鹅89。
- 成因：央视网/光明网/绍兴卫健委等二手科普文章误把"鹅肝376.9"写成"鹅肉376.9"，本库 C052 的 sources 含"国家卫健委食养指南2024相关解读"，即沿用了该二手误读。
- 后果：把一种本应"缓解期可适量（中嘌呤）"的禽肉，错误标注为"严格禁止"的极高嘌呤，直接误导患者。
- **建议修正**：C052 鹅肉改为 ~89–140（生鹅肉；可参照烧鹅89并给 range[89,140]），level 改"中"，note 注明"指南表1-1将鹅列入75–150第二类；377为鹅肝值，勿混淆"。

### 🟡 存疑 / 需加注（建议修正）

**D2. 沙丁鱼(SH055) 鲜品=82（中）与临床共识冲突**
- 库值 82 确实是《中国食物成分表》第6版原文（转录无误），note 也已区分罐头版(SH108)。
- 但：上海卫健委分类表、光明网引数据均把沙丁鱼列为 150–1000 第一类，常用值 ~295。差异常源于测定口径（鲜品小鱼 vs 罐头/干制全鱼）。
- **建议**：保留 82，但在 note 显著提示"临床通用表多将沙丁鱼列为极高嘌呤(~295)，本品为食物成分表鲜品值，痛风患者仍应避免食用沙丁鱼及罐头"。

**D3. 干贝(SH089)=193 vs 广东中医药局表 390**
- 差异约 1 倍，源于样本（鲜干贝 vs 干制品不同含水率/口径）。库取中国食物成分表口径可接受，但建议在 note 标注"因干制程度不同差异大，干贝/干海产普遍极高，宜避免"。

**D4. 芦笋(S051)：purine=null 却带 range=[150,150]、level=未知**
- 芦笋在旧临床表中常列 ~150（中高），2024 指南表1-2未列。null 与固定 range 并存，用户看到 range=150 却显示"未知"会困惑。
- **建议**：要么补值（参照旧表给 ~150 并标"中，植物嘌呤影响小"），要么把 range 去掉只留定性 note。

### 🟢 建议补充（非错误）

**S1. 缺带鱼（最突出遗漏）**
- 带鱼是中国消费量最大的海鱼之一，嘌呤约 291–392 mg/100g（高/极高），且知识库 diet-3《红灯黑名单》**明确点名"带鱼"**。数据库却未收录（SH027 刀鱼=161 是长江刀鱼/长颌鲚，非带鱼）。
- **建议**：新增"带鱼"条目，取值 ~290（或 range[291,392]），level=高，归入水产鱼类。

**S2. 其他可补常见食物**：韭菜、蒜苔/蒜苗、葡萄(通用名)、榴莲等常见果蔬未收；大蒜(T015)、生姜(T014)、洋葱(S053)、紫甘蓝(S052)、鲜牛奶(M003)等标"未知"合理但可补定性。均属锦上添花，不影响可信度。

### 关于"未知"条目的说明（核查通过）
- 共 30 条 null 值。其中啤酒、黄酒、白酒、鲜牛奶、酸奶、奶油、黄油、咖啡、苏打水、洋葱、紫甘蓝、草莓、橙子、猕猴桃、鸡精、味精、酵母粉、浓肉汤等，**2024 指南表 1-2 确实未列具体数值**，库中以 null + 定性 note 处理，符合"绝不编造精确数值"的承诺，处理得当。
- 26 条 null 同时带 range（如啤酒[5,10]、鸡精[300,500]、酵母粉[500,1000]）：range 来自 WS/T560 或临床表，作为参考区间合理；但建议统一说明"range为参考区间，非精确测定值"。

## 五、知识库医学审核结论（23 篇全审）

对照《中国高尿酸血症与痛风诊疗指南(2019)》、2024 食养指南、《内科学》第9版、2020 ACR 指南逐条核对：

| 核查点 | 知识库表述 | 结论 |
|---|---|---|
| 高尿酸诊断阈值 | 血尿酸 >420 μmol/L | ✅ 正确（2024指南：非同日2次空腹>420） |
| 降尿酸目标值 | 一般<360；有痛风石<300 μmol/L | ✅ 正确（myth-4/med-3/visit-3 三处一致） |
| 分期（四期） | 无症状高尿酸→急性关节炎→间歇期→慢性痛风石 | ✅ 正确 |
| 急性期用药 | 秋水仙碱/NSAIDs/糖皮质激素，不降尿酸 | ✅ 正确 |
| 缓解期降尿酸药 | 别嘌醇、非布司他（抑生成）；苯溴马隆（促排泄） | ✅ 分类正确 |
| 别嘌醇 HLA-B*5801 风险 | 建议基因检测、从小剂量 | ✅ 正确，符合中国人群指南 |
| 非布司他心血管风险、苯溴马隆肾结石/肾功能禁忌 | 均提示 | ✅ 正确 |
